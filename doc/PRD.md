# PRD · 需求规格

> 状态：定稿（v1.0 · 2026-08-29） · 最近更新：2026-08-29

## 1. 背景与目标

- 痛点：
  - 常用脚本大多是 macOS 原生的 `.sh` / `.command` 文件，散落在不同目录，靠记忆与手输命令执行。
  - 本地代码项目分布在多个根目录（当前主要在 `~/pinge-system/code`），时间久了想不起当初用途。
- 目标：一个 Electron 桌面工作台（macOS 单平台），可视化集中管理脚本与项目。
- 成功标准：
  - 找脚本 → 点卡片一键执行 → 在应用内日志面板看结果。
  - 找项目 → 看用途说明 → 一键在 VS Code / 终端 / 文件夹中打开。
- 非目标（一期）：参数表单、项目快捷命令、常驻/全局快捷键、跨平台。

## 2. 用户与场景

使用者：本人（个人开发/自用工具，单机使用）。

典型场景：

1. 执行脚本：早上想跑“黄金价格提醒”——打开工作台 → 脚本页 → 点击卡片 → 应用内日志面板实时看输出。
2. 找回项目：想找之前写的某个 Java 项目——项目页关键词搜索 → 查看用途说明与标签 → 一键在 VS Code 打开。
3. 登记新项目：新项目文件放好后——配置扫描根目录或手动添加 → 自动识别技术栈/README 草稿 → 补充说明后登记完成。
4. 新脚本入库：写了一个新的 `.command` 工具——选择文件手动添加，或扫描目录后勾选登记。

## 3. 功能需求

### 3.1 脚本管理

- 展示：卡片/列表展示，按分组归类；支持搜索。
- 记录字段：名称、描述、所属分组、执行方式（脚本文件路径为主 / 自定义命令高级模式）、运行目录、执行 Shell（默认 `zsh`，单脚本可切 `bash`）、图标/颜色（预设）。
- 执行：一键执行；应用内日志面板（stdout+stderr 合并、实时滚动、可复制、可清空当前输出）；显示状态/耗时/退出码；可手动停止（终止进程树）。
- 历史记录：仅保留最近 5 次运行，可一键清理。
- 安全：单个脚本可设“执行前需确认”（默认关）。
- 添加方式：
  - 手动填表单（选脚本文件或填自定义命令）。
  - 扫描指定目录自动发现（识别 `.sh` / `.command` / `.py` / `.js` 等；递归；排除 `.git` / `node_modules` / 隐藏目录）；发现结果列清单，勾选确认后登记。
- 二期候选：参数表单、项目快捷命令、交互式脚本“新终端打开”、自定义图标上传。

### 3.2 项目仓库管理

- 记录字段：名称、本地路径、用途说明、语言/技术栈、标签、维护状态（活跃/维护中/归档）、Git 远程地址。
- 添加方式：
  - 手动添加。
  - 多根目录自动扫描 git 仓库（默认根目录 `~/pinge-system/code`，可在设置中增删）。
- 用途说明：手动填写为主；扫描时自动读取 README 标题/简介作为草稿（可修改）。
- 技术栈：手动选择 + 扫描时按扩展名自动猜测（可修改）。
- 快捷操作：打开文件夹、在终端打开（默认系统 Terminal）、在编辑器（VS Code）打开、复制路径。
- Git 信息：当前分支、最近一次提交、是否有未提交改动；打开项目时刷新，另提供手动刷新按钮。
- 筛选与展示：按名称/标签/说明搜索；按维护状态筛选（含“只看活跃”）；归档项目折叠；卡片/列表视图切换。
- 一期不做：项目快捷命令（二期）、最近打开时间排序。

### 3.3 设置与通用能力

- 窗口结构：单窗口三个页签——脚本 / 项目 / 设置。
- 搜索：名称/标签/说明模糊搜索（脚本、项目均支持）。
- 主题：深浅色，跟随系统 + 手动覆盖。
- 数据：SQLite；数据目录用 Electron 默认目录；支持导出 JSON 备份；支持导入恢复（导入前自动备份当前数据）。
- 设置页：扫描根目录管理、默认编辑器/终端、主题、视图等。

## 4. 非功能需求

- 性能：启动快；日志实时滚动不卡顿；目录扫描可取消。
- 数据安全：全部本地存储、不上传；危险操作可配置确认。
- 兼容性：macOS 单平台（Apple Silicon / Intel 双架构，Deploy 阶段验证）。
- 可维护性：React + TS 统一技术栈，分层清晰，数据可备份迁移。

## 5. 验收标准总览

### 脚本模块

- 可新增/编辑/删除脚本（文件路径与自定义命令两种执行方式）。
- 分组可新建/重命名/删除，脚本可归类。
- 扫描目录可发现脚本文件，勾选后登记；排除规则生效。
- 点击执行：日志面板实时显示输出、状态、耗时、退出码。
- 运行中可停止，进程树被终止。
- 历史仅保留最近 5 次，可一键清理。
- 设了“执行前确认”的脚本，执行前弹出确认。

### 项目模块

- 可手动添加；多根目录扫描可发现 git 仓库并登记。
- 卡片/列表展示全部字段；技术栈自动猜测可修改。
- README 自动草稿用途说明，可修改保存。
- 维护状态筛选（含只看活跃）与归档折叠可用。
- 打开文件夹 / 终端 / VS Code / 复制路径四个操作可用。
- Git 信息（分支/最后提交/未提交改动）正确，手动刷新可用。

### 通用

- 搜索（名称/标签/说明）、深浅主题、卡片/列表切换可用。
- 导出 JSON 备份；导入恢复可用，导入前自动备份当前数据。

## 6. 已知限制与备选方案

- 应用内执行无法完整模拟“双击 .command 在 Terminal 中运行”的交互终端体验；需要键盘交互的脚本一期不友好，候选方案是二期做“新终端打开”。
- 依赖 `sudo` 或需要输入密码的脚本在应用内执行会失败/挂起，需改用自定义命令配合无密码场景，或等二期新终端方案。
- 大目录递归扫描可能耗时：扫描可取消，后续可加增量扫描。
