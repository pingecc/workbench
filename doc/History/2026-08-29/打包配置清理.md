# 打包配置清理（electron-builder 建议）

> 类型：工程优化 · 日期：2026-08-29

- 按 electron-builder 输出建议移除多余的 `@electron/rebuild` 依赖（连带 56 个依赖包），`postinstall` 改为 `electron-builder install-app-deps`，删除不再需要的 `rebuild` 脚本。
- 效果：`npm install` 后仍会自动构建 better-sqlite3 匹配 Electron 版本，`npm run pack:mac` 输出不再出现「@electron/rebuild not required」提示。
- 遗留提示（不影响使用）：默认 Electron 图标（待 M3 自定义图标）、未签名（个人自用，首次“右键 → 打开”）。
