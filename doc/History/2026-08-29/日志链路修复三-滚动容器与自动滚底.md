# 日志链路修复（三）：滚动容器 + 自动滚底

> 类型：缺陷修复（用户实测反馈迭代）· 日期：2026-08-29

- 根因：`.log-panel` 不是 flex 布局，`.log-area` 的 `flex: 1` 失效 → 日志区被内容撑高且自身无滚动条，外层 `.modal` 又 `overflow: hidden` 直接裁剪下面内容，视口钉在开头，看起来「只留下最开始打印的日志」。
- 修复：`.log-panel` 改为 `flex-direction: column`，`.log-area` 加 `min-height: 0` 成为真正的滚动容器；自动滚底逻辑加「用户在底部才跟随」守卫（用户上翻查看时不打扰）。
- 顺带修复：执行器入库前对整段组装文本再执行一次 `cleanLogText`，消除被 chunk 边界劈开的 ANSI 序列残留（此前入库文本偶尔残留 `\x1b[33m` 之类片段）。
- 验证（隔离 userData + CDP 驱动的真实应用 E2E）：读取 DOM 连续采样 8 秒，`scrollTop` 从 0 平滑跟随到 271，结束时 `scrollTop + clientHeight = scrollHeight`（恰好钉底）；入库历史 0 个残留 ESC 字节；typecheck / eslint / build / pack 通过，已重新打包 release .app 并替换用户正在运行的应用。
