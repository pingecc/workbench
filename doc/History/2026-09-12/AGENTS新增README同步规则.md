# AGENTS 新增 README 同步规则

> 类型：项目约定变更 · 日期：2026-09-12

## 背景

此前新增功能后 README 的功能介绍与截图依赖人工提醒，存在 README 与实际功能脱节的情况（如界面预览截图滞后于功能迭代）。

## 变更内容

- 在 `AGENTS.md` 的「文档与变更记录规则」小节新增一条约定：每次新增功能，必须同步更新 `README.md`，补充新功能介绍，并启动应用自动截图，把界面截图配到对应介绍处，保持 README 与实际功能一致。

## 验证方式

- 查看 `AGENTS.md` 该小节，确认新规则已生效，后续新增功能时按此执行。
