# 备忘模块需求确认与原型定稿

> 类型：需求与设计 · 日期：2026-08-30

- 新增「备忘」模块：统一记录想法与待办任务，数据本地 SQLite 存储、纳入 JSON 备份。
- 需求确认（用户均采纳推荐方案）：
  - 模块形态：单页签「备忘」（侧边栏第 3 项，脚本/项目之后），用类型（想法 / 待办）区分，不拆两个页签。
  - 字段：通用——标题（必填）、正文（可选多行）、类型、创建/更新时间；待办专属——完成状态、截止日期（可选）、优先级（高/中/低，可选）；想法不设完成/截止/优先级。
  - 排序与筛选：未完成优先 + 创建时间倒序；筛选「全部 / 想法 / 待办」；已完成折叠；想法按创建时间倒序。
  - 正文形态：纯文本多行，不做 Markdown 渲染。
- 明确不做（v1）：提醒/通知（与「普通窗口应用、不常驻」既有决议冲突）、子任务、重复任务、Markdown、云同步。
- 原型：`prototype/notes-prototype.html`（静态稿，贴合现有浅/深主题与组件风格），用户确认通过。
