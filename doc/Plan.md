# Plan · 总体方案与里程碑

> 状态：定稿（v1.1 · 2026-08-30） · M1 一期完成 + 备忘模块（M4）完成 · 最近更新：2026-08-30

## 1. 技术选型

已确认：

- 应用壳：Electron（macOS 单平台，普通窗口应用）。
- 前端：React + TypeScript。

建议默认：

- 脚手架：electron-vite（统一主进程 / 预加载 / 渲染进程构建）。
- 数据：better-sqlite3（同步 API，简单可靠）。
- 日志执行：Node `child_process.spawn`，按行推送日志；停止时终止进程树。
- 系统集成：`open` / `code` 命令打开文件夹、终端、VS Code。
- 状态管理：按复杂度选用 Zustand 或 React 内置状态。

## 2. 总体架构

- 渲染进程（React + TS UI）：脚本页 / 项目页 / 设置页，卡片列表、日志面板、表单。
- 主进程服务（Node）：脚本执行（spawn + 进程树终止）、项目扫描（git 发现 / 技术栈猜测 / README 读取）、系统集成（打开文件夹 / 终端 / VS Code / 复制路径）、Git 信息获取。
- 通信：预加载脚本 + contextBridge 暴露受限 IPC API，渲染进程不直接接触 Node/文件系统。
- 数据层：SQLite（Electron userData）存脚本/项目/分组/设置/运行历史；JSON 备份导出与导入。

### M1 范围清单

- 工程脚手架（electron-vite + React + TS + better-sqlite3 + 打包冒烟）。
- 脚本：CRUD、分组、扫描勾选登记、一键执行 + 日志面板 + 停止、历史 5 条、执行前确认。
- 项目：CRUD、多根目录扫描 git 仓库、README 草稿、技术栈猜测、状态筛选/归档折叠、四个快捷操作、Git 信息。
- 设置：扫描根目录管理、默认编辑器/终端、主题、视图。
- 数据：SQLite 落库、导出 JSON 备份、导入恢复（导入前自动备份）。
- 发布：electron-builder 打包双架构 .app。

### M4 范围清单（备忘模块）

- 备忘：想法/待办统一记录，单页签；标题 + 正文 + 类型 + 待办专属字段（完成 / 截止日期 / 优先级）。
- 交互：新建/编辑/删除、勾选完成（已完成折叠）、类型切换、筛选与搜索、待办按优先级 + 创建时间排序。
- 数据：`notes` 表（v3 迁移）；JSON 备份导出/导入同步。

## 4. 风险与依赖

- Electron + better-sqlite3 需要本机编译环境（Xcode Command Line Tools / node-gyp）。
- 大目录扫描可能耗时 → 扫描可取消，后续可增量。
- 应用内执行对交互式脚本支持有限 → 已列入已知限制。
- 当前只做 macOS；后续跨平台需重新验证。
