# Test · 测试策略与验收

> 状态：定稿（v1.0 · 2026-08-29） · 与 PRD 第 5 节验收标准一一对应

## 1. 测试范围与策略

- 个人自用工具：以**手工测试**为主，随 T 任务完成同步验证。
- 当前状态（2026-08-29）：M1 代码已完成并通过构建与启动冒烟，以下验收清单等待人工逐项勾验（`npm run dev` 或打开 `release/mac-arm64/Workbench.app`）。
- 备忘模块（M4，2026-08-30）：新增验收清单与手工用例，随开发同步验证。
- 建议少量单元测试（如写代码时引入轻量测试，保持简单）：脚本扫描排除规则、历史裁剪到 5 条、备份导入导出。
- UI 交互按下方清单逐项勾验。

## 2. 功能验收清单

### 脚本模块

- [ ] 新增/编辑/删除脚本（文件路径与自定义命令两种执行方式）。
- [ ] 分组新建/重命名/删除，脚本可归类。
- [ ] 扫描目录发现 `.sh` / `.command` / `.py` / `.js`，排除 `.git` / `node_modules` / 隐藏目录，勾选后登记。
- [ ] 一键执行：日志面板实时显示输出、状态、耗时、退出码。
- [ ] 运行中可停止，子进程树确实终止。
- [ ] 历史仅保留最近 5 次，可一键清理。
- [ ] 设了“执行前确认”的脚本运行时弹确认框。

### 项目模块

- [ ] 手动添加与多根目录扫描 git 仓库。
- [ ] 卡片/列表展示全部字段；技术栈自动猜测可修改。
- [ ] README 自动草稿用途说明，可修改保存。
- [ ] 维护状态筛选（含只看活跃）与归档折叠。
- [ ] 打开文件夹 / 终端 / VS Code / 复制路径可用。
- [ ] Git 信息（分支 / 最后提交 / 未提交改动）正确，手动刷新可用。

### 备忘模块

- [ ] 新建/编辑/删除备忘；类型可在想法/待办间切换，待办专属字段随类型显示/隐藏。
- [ ] 待办勾选完成/取消完成；已完成条目默认折叠展示。
- [ ] 筛选（全部/想法/待办）与标题/正文搜索可用。
- [ ] 排序符合「未完成优先 + 创建时间倒序」。
- [ ] 导出备份 → 清空 → 导入，备忘数据完整恢复（导入前自动备份旧数据）。

### 通用

- [ ] 搜索（名称/标签/说明）。
- [ ] 深浅主题、卡片/列表切换。
- [ ] 导出 JSON 备份；导入恢复（导入前自动备份当前数据）。

## 3. 手工测试重点用例

| 编号 | 前置条件 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| H1 | 已登记一个输出多行日志的脚本 | 点击执行并观察 | 日志逐行实时滚动，结束时显示退出码 0 与耗时 |
| H2 | 脚本路径含中文或空格 | 执行该脚本 | 正常运行，无路径转义问题 |
| H3 | 运行一个 sleep 类脚本 | 点击停止 | 状态变为已停止，进程树无残留 |
| H4 | 扫描根目录含 node_modules 的大目录 | 发起扫描 | 可取消；node_modules/.git/隐藏目录不被登记 |
| H5 | 某脚本已运行 6 次 | 查看历史 | 仅显示最近 5 条 |
| H6 | 已有若干数据 | 导出备份 → 清空数据 → 导入 | 数据完整恢复，导入前生成旧数据存档 |
| H7 | 已有若干备忘 | 新建/编辑并切换类型保存 | 字段随类型正确显示/隐藏，数据不丢 |
| H8 | 列表超过一屏 | 勾选某待办为完成 | 条目划线并移入「已完成」折叠区；取消勾选则回到未完成 |
| H9 | 已有若干备忘（含待办/想法） | 筛选「想法/待办」并搜索关键词 | 分区与搜索符合预期，无匹配时显示空态提示 |
