# Workbench 桌面工作台 · 项目文档索引

> 状态：**M0 定稿 + M1 一期完成（v0.1.0）+ 备忘模块完成（v0.2.0）** · 最近更新：2026-08-30

## 项目目标

一个本地桌面工作台，集中管理与执行三类日常事务：

1. **脚本管理**：把散落的常用脚本集中登记、可视化展示、一键点击执行。
2. **项目仓库管理**：把分散在不同本地文件夹下的代码项目集中登记、可视化浏览，避免“忘了这个项目当初是干嘛的”。
3. **备忘**：随手记录想法与待办任务，待办可勾选完成、按优先级与截止日期管理。
